## User

what is the support.js file inside this project ?

## Assistant

`support.js` is the runtime that lets your `.dc.html` design files work. Each portfolio file loads it, and it renders the design in the browser. It also handles the live preview, editing, and imports between design files.

You don't need to edit it, and it's managed for you. If you delete it, the portfolio files stop rendering. If you export or hand off the project, keep it in the same folder as the `.dc.html` files.
